# Juntar CSVs em Python

Script do vídeo: une vários `.csv` de uma pasta em um arquivo só, pulando cabeçalhos duplicados.

```bash
python juntar_csvs.py
python juntar_csvs.py -i dados -o saida/consolidado.csv
```

A pasta `dados/` traz 3 CSVs de exemplo. A saída vai para `saida/consolidado.csv` (utf-8-sig para abrir bem no Excel).
